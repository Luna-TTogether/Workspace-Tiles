# Workspace Tiles

Workspace Tiles 是一个轻量的 Chrome 新标签页工作区启动器。它用磁贴按项目整理常用网站、书签和当前打开的标签页，无需注册账号，工作区数据保存在本机。

## 主要功能

- 在新标签页显示工作区磁贴
- 翻转工作区卡片查看并编辑本地便签，支持 `- [ ]` / `- [x]` 清单
- 创建、重命名、删除和排序工作区
- 添加、编辑、删除和排序工作区中的网站
- 从 Chrome 书签选择文件夹或网站并批量导入
- 从当前窗口选择已打开的标签页并批量导入
- 向新工作区或已有工作区添加网站
- 打开单个网站，或在当前窗口、新窗口中打开整个工作区
- 导出全部工作区、网站和排列顺序为本地 JSON 备份
- 从有效的 Workspace Tiles 备份文件恢复数据
- 在简体中文和英文之间即时切换
- 支持直接拖动工作区和网站排序
- 支持浅色、深色和窄屏界面
- 通过扩展图标或快捷键把当前页面快速加入最近使用的工作区

## 本地安装

1. 打开 Chrome 扩展管理页：`chrome://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前 `Workspace Tiles` 文件夹

项目使用浏览器原生 ES Modules，不需要构建步骤或运行时第三方依赖。

## 备份与恢复

左下角管理面板提供“导出备份”和“导入恢复”：

- 导出会将全部工作区、网站、便签、卡片显示面、ID 和排列顺序保存为 UTF-8 JSON 文件
- 备份文件只保存到用户选择的位置，不上传到开发者服务器
- 导入前会完整校验文件，并显示备份与当前数据的工作区和网站数量
- 导入会完整替换当前数据，不会与当前工作区合并
- 写入失败时保留原数据，并提示当前数据未更改

建议在卸载扩展、迁移电脑或进行重要调整前导出备份。

## 语言

界面支持：

- 简体中文
- English

用户可以在管理面板中即时切换语言，语言偏好保存在本机。界面文案集中在 `i18n.js`，扩展名称和商店摘要使用 Chrome `_locales` 目录。

## 权限与数据

- `storage`：在 `chrome.storage.local` 中保存工作区、网站、便签、卡片显示面、排列顺序和语言偏好
- `favicon`：读取 Chrome 已保存的网站图标，用于在工作区中识别网站
- `bookmarks`（可选）：仅在用户主动从书签导入时申请
- `tabs`（可选）：仅在用户主动从当前窗口导入标签页时申请
- `activeTab`：仅在用户点击扩展图标或使用快捷键时读取当前页面的标题和 URL

用户拒绝可选权限后，仍然可以手动创建工作区和添加网站。Workspace Tiles 不要求账号，也不会把工作区或备份上传到开发者服务器。

快捷加入的默认建议按键是 `Alt+Shift+W`，可以在 `chrome://extensions/shortcuts` 中修改。

网站图标从 Chrome 的本地 favicon 数据中读取，并缓存在 Workspace Tiles 的本地 IndexedDB 中。图标不会发送给开发者或第三方，也不会包含在备份中；无可用图标时立即显示网站名称的首个字符。

## 开发检查

界面规范见 `DESIGN_SYSTEM.md`，项目级实现约束见 `AGENTS.md`。

运行完整测试：

```sh
npm test
```

仅运行项目 UI 审计：

```sh
npm run check
```

检查脚本不需要安装第三方依赖。

## 字体许可

界面使用随扩展打包的 Geist Sans，字体与 SIL Open Font License 见 `fonts/` 目录。
