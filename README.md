# Workspace Tiles

一个轻量 Chrome 新标签页工作区插件，用磁贴管理常用网站组合。

## 使用

1. 打开 Chrome 扩展管理页：`chrome://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前文件夹：`Workspace Tiles`

## MVP 功能

- 新标签页显示工作区磁贴
- 本机保存到 `chrome.storage.local`
- 添加、重命名、删除工作区
- 首页工作区支持拖拽和键盘排序
- 新建工作区时可从 Chrome 书签选择文件夹或网站并平铺导入
- 新建工作区时可选择当前窗口已打开的标签页并平铺导入
- 已有工作区可从手动输入、Chrome 书签或当前窗口标签页继续添加网站
- 添加、编辑、删除网站
- 工作区详情中的网站支持拖拽和键盘排序
- 左下角管理面板支持导出备份、导入恢复，并展示版本、作者、联系方式和支持入口
- 管理面板支持在简体中文与英文之间即时切换，语言偏好保存在本机
- URL 自动补 `https://`，并支持保留特殊协议地址
- 网站名称为空时使用域名
- favicon 使用 Google favicon 服务，失败时显示名称首字母
- 单个网站点击后在当前标签页打开
- 打开全部支持当前窗口和新窗口

## 权限

默认只申请 `storage` 权限。“从书签添加”和“从打开的标签页添加”首次使用时，分别按需申请可选的 `bookmarks` 和 `tabs` 权限；用户拒绝后仍可手动创建工作区。新窗口打开全部通过 `chrome.windows.create` 调用，不需要额外声明权限。

## 字体许可

界面使用随扩展打包的 Geist Sans，字体与 SIL Open Font License 见 `fonts/` 目录。

## 开发检查

界面规范见 `DESIGN_SYSTEM.md`，项目级实现约束见 `AGENTS.md`。修改功能后运行：

```sh
npm run check
```

检查脚本不需要安装第三方依赖。多语言文案集中在 `i18n.js`，扩展名称和描述使用 Chrome `_locales` 目录。
